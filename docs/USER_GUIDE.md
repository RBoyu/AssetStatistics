# 资产账本使用指南

本地中文桌面资产管理程序，支持银行存款和股票、基金、ETF 等投资持仓。使用 Python 标准库、Tkinter、SQLite，无需安装 pip 依赖或联网。

## 启动

Python 3.10+，包含 Tkinter / SQLite。新项目通过 uv 管理环境，固定 Python 3.13.16；环境与迁移说明见 [项目说明](../README.md)。

- 在 PyCharm 中选择新项目的 `.venv` 解释器，再运行 `AssetStatistics.py`。
- 双击 `StartAssetBook.cmd`。
- 命令行：`uv run --locked assetbook`。
- 只读检查：`uv run --locked assetbook --check`。
- 指定其他账本目录：`uv run --locked assetbook --data-dir "D:\MyAssets"`。

开发模式以新项目根目录解析默认数据路径，从任何工作目录启动都使用新目录中的同一份账本。

## 存款与投资

选择“活期”或“定期”登记存款本金、币种、银行、日期、利率与续期约定。定期自动辅助计算到期日期，可手动调整。到期提醒默认提前 30 天，可在设置中调整为 1–365 天。

新增时默认填今天的存入日期，并立即算出所选定期期限的到期日。选择定期类型、输入存入日期或修改期限（月）时实时重算，无需点击其他控件；修改期限月数也会同步定期类型。日期输入未完成或无效时清空自动到期日，正确填写后恢复计算，支持月底和闰年。“今天”按钮可快速重设存入日期。

到期日默认勾选“自动计算到期日”，计算结果直接显示在到期日期输入框内，以浅绿色底色标明，自动模式只读。修改存入日期或期限后，框内日期立即刷新；保存采用框内显示的日期。需要使用银行提供的特殊到期日时，取消勾选即可手动填写；此时修改日期或期限不会覆盖手动到期日。编辑既有记录时，若原到期日与登记期限不同，会自动使用手动模式保留原值，重新勾选则恢复计算。股票、基金等投资仍无到期日。

选择“股票”“基金”“ETF”“其他投资”登记券商 / 平台、持仓市值、币种、买入 / 建仓日期、账户及标的名称 / 代码备注。也可输入“指数基金”等自定义投资类型。**投资表单隐藏期限、到期日、固定年利率和续期方式**；保存与导入时会清除这些不适用的存款字段。投资显示“持有中”，不进入到期计划，也不估算固定利息。

投资金额为手动登记的当前持仓市值；可通过“编辑”更新，操作历史保留前后值。卖出后可结清记录，结清记录不再计入在账资产。未接入实时行情，也没有自动计算浮动盈亏。

总览和分析中的在账资产总额 = 存款本金 + 登记的投资市值。各币种独立统计，不折算汇率。“预计整期利息”和“存款按年利率估算”仅统计非投资资产。

## 工作流程

- 资产明细：银行、券商、账户、备注搜索，机构 / 币种 / 状态筛选，点击列头排序，双击查看详情。
- 搜索可组合 `工行`、`未来30天到期`、`超过5万`、`本月到期`。投资可选择状态“持有中”，也可搜索“股票”“基金”或备注中的标的代码。
- 智能录入：`工行 5万元 三年 利率2.1% 2026-10-10 自动续期`；`中信证券 股票 市值3万元 2026-10-10 贵州茅台 600519`；`招商银行 基金 2万元`。本地规则仅填写表单，核对后保存；投资录入原文保存在备注中。
- 到期日历：已到期、提醒期内到期和后续计划，仅包含有到期日的非投资资产。程序打开期间每分钟刷新；关闭后不在后台提醒。
- 分析：机构、资产类型、续期方式、存入 / 建仓月份和未来到期本金分组。月份统计按当前登记日期与金额分组，包含已结清记录，不代表历史净资产或收益曲线。SVG 可导出完整分组图表。
- 导入：CSV / JSON / SQLite，先预览错误和疑似重复，默认跳过重复，可主动选择保留；确认后事务写入，失败整批回滚。
- 导出：当前筛选记录可导出 Excel / CSV / JSON。金额隐藏只影响界面，导出仍保留完整数据。Excel 账号为文本，保留前导零。CSV 可能被当作公式的文本加前置单引号；JSON 保留完整文本。
- 删除为软删除，在“已删除”状态中可恢复；结清后也可以重新打开。

## 数据与备份

当前数据库仍为 `assets_v4.db`；4.1 没有修改数据库结构，兼容 4.0 的完整快照。首次从旧目录运行仍支持迁移 `deposits.db` 和 `deposits.json`；每个来源只导入一次，保留原始字段、旧编号、账户和续期次数。所有既有记录保留。

此次清理将旧 `theme.py`、`config.json`、`build_info.json`、`install_requirements.py`、`requirements.txt` 和已迁移的 `deposits.db` / `deposits.json` 从主目录移除。它们已存入 `backups/pre41_program_*.zip`，清理列表及哈希在 ZIP 内的 `cleanup_manifest.json`。Python 缓存文件可自动重建，清理时删除。主目录保留启动入口、模块、当前数据库、图标、说明、测试和日志。

`backups` 中的既有文件不改写、不删除。新版快照以 `assetbook_` 开头；默认每天首次打开创建一次，导入 / 恢复前自动创建快照。SQLite 备份 API 确保一致性；文件名包含微秒，避免覆盖。

恢复会替换当前账本。系统先验证完整性与结构，再备份当前数据库为 `before_restore`，需要回退时选择该快照。旧版存款 .db 可以直接恢复为新版记录，新版快照包括历史和设置。旧版恢复保留当前操作历史并记录恢复动作。

## 计算约定

金额用 Decimal，最多两位小数。未开始、已删除、已结清和日期待核对的记录不计入在账资产。到期存款在结清前仍计入本金。状态随上海日期（UTC+8）推导，查看页面不写回业务数据。

月期限按日历处理月底 / 闰年。存款利息为单利估算：本金 × 年利率 / 100 × 期限年数；匹配完整月份时使用月数 / 12，其余使用实际天数 / 365。不含税费、提前支取条款或复利，实际到账以银行为准。

自动续期选项仅记录银行约定；核对实际本金、利率与日期后手动登记新一轮。上一期信息在历史中保留。股票、基金等投资禁止登记续期。

## 快捷键与诊断

`Ctrl+N` 新增，`Ctrl+F` 搜索，`Ctrl+Shift+P` 隐藏 / 显示金额，`F5` 刷新；表单中 `Ctrl+Enter` 保存，`Esc` 关闭。

日志在 `logs/assetbook.log`，自动轮换。账号默认只显示最后四位，原始导入记录与导出文件保留完整信息。

代码分层：`domain.py` 计算 / 搜索 / 校验；`storage.py` 事务 / 数据 / 历史 / 备份；`ui.py` 桌面界面；`export.py` Excel / SVG。

测试：`uv run --locked python -B -m unittest discover -s tests -v`。51 项测试覆盖业务规则、投资流程、实际表单联动和 uv 启动，包括自动默认日期、实时改日期 / 期限、月底 / 闰年、手动模式保留特殊日期、智能录入、立即保存、数据路径和只读诊断。GUI 测试需要可用的 Tk 显示环境；无显示环境或受限沙箱无法加载 Tcl 资源时跳过界面测试。本次迁移已在普通 Windows 窗口中验证实际界面启动和自动到期日联动。
